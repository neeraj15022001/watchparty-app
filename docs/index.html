The Watch Party Platform That
Never Compresses Your Video

Say goodbye to blurry 720p re-encoded streams. WatchParty Pro delivers pristine, native 4K/HDR synchronized streaming for Netflix, YouTube, direct URLs, and local files—complete with real-time WebRTC voice/video and smart voice ducking.

Get Started in 60 Seconds How It Works

Engineered for Perfectionists

Why settle for pixelated screen captures when you can stream at original quality?

🍿

Native 4K / HDR OTT Sync

Hooks directly into your authenticated Netflix, YouTube, or Prime Video player via a lightweight Manifest V3 extension. You get official CDN bitrates, Dolby Vision, and HDR10 untouched.

⚡

HTTP 206 Range Streaming

Load local movie files on your machine with zero server re-encoding. Our server handles HTTP 206 Partial Content byte ranges, giving all room participants instant timeline scrubbing and multi-gigabyte seekability.

⏱️

Sub-200ms NTP Drift Control

Implements Cristian's algorithm over WebSockets to calculate network latency and hardware clock skew. Soft speed-nudge (0.95x–1.05x) keeps everyone in imperceptible sync without jarring jumps.

🎙️

Smart Voice Ducking

Powered by the Web Audio API. When a friend speaks into their microphone, the movie volume gently attenuates by 40% so you can hear each other, smoothly restoring full volume when speech finishes.

📹

Decoupled WebRTC Mesh

Audio and video communication runs on an independent WebRTC peer-to-peer layer with hardware echo cancellation and noise suppression. Network blips on webcams never interrupt movie playback.

🛡️

Zero Dependencies

The backend is written in pure Python 3 using standard library asyncio and socket. No npm install, no heavy pip dependencies, no container bloat. Just run and watch.

Quickstart Guide

Up and running on your machine in under a minute.

1

Clone the Repository

git clone https://github.com/neeraj15022001/watchparty-app.git
2

Launch the Python Server

cd watchparty-app && python3 server.py

Runs with zero dependencies on macOS, Linux, and Windows.

3

Open the Cinema Interface

http://localhost:8080/?room=cinema-night

Share the link with your friends on your local network or via Cloudflare Tunnel.

4

Load the Extension (Optional for OTT)

Navigate to chrome://extensions in Chrome/Brave/Edge, toggle Developer mode, click Load unpacked, and select the extension/ folder.

Project Changelog

Documenting releases, architectural enhancements, and milestone updates.

v1.1.0 (Latest) September 16, 2026

HTTP 206 Range Streaming & Open Source Preparation

  • HTTP 206 Partial Content Engine: Added byte-range streaming in server.py to allow smooth timeline scrubbing and multi-tab seek synchronization for large local video files.
  • Local File Path Loader: Introduced /api/load-local-path for instant symlinking/copying of local machine video paths with zero upload latency.
  • Loopback Stream Uploader: Added /api/upload supporting real-time streaming file uploads with dynamic progress indication.
  • Open Source Governance: Added comprehensive MIT License, Contributing Guide, Security Policy, Code of Conduct, and GitHub Issue/PR templates.
  • AI Transparency Disclosure: Published AI_DISCLOSURE.md outlining human-in-the-loop AI engineering methodology.
  • GitHub Pages Deployment: Created automated GitHub Actions workflow to publish project website and changelog.
v1.0.0 September 15, 2026

Initial Core Engine Release

  • Async Signaling Server: Pure Python zero-dependency RFC 6455 WebSocket server implementation.
  • NTP Clock Synchronization: Implemented Cristian's algorithm to measure round-trip time and machine clock skew.
  • Dynamic Playback Steering: Sub-200ms drift correction with smooth playbackRate adjustment (0.95x–1.05x).
  • WebRTC Voice & Video Mesh: Integrated peer-to-peer audio/video chat with hardware echo cancellation.
  • Smart Voice Ducking: Web Audio API volume attenuation engine that automatically reduces movie volume during speech.
  • Manifest V3 Companion Extension: Player event interceptor for Netflix, YouTube, and Prime Video.
